## 2. Verified versus advertised

* **Verified on 2026-10-30:** all twelve root workspace packages passed fmt, the clippy gate, and
  workspace tests (359 passed, including one doctest), with 56 live simulation assertions and the
  headless browser checks at 27 loopback / 31 shared, zero console errors. The drafting editor was
  driven as a user would: a line is drawn by clicking two points, saved as a `.zdraft`, and a shared
  session downloads the STL, the DXF and a plotted PDF through the token. A plotted A3 sheet was
  rendered and inspected, and `pdftotext` extracts every title-block field. Evidence is in
  `engineering/quality/{builds,tests}.json` and `docs/build-and-test.md`. The cache cycle was not
  browser-driven; the revolve, arc-sector and named-revision cycles were, in headless Chrome (11 DOM
  assertions for revolve, 3 for the sector, 4 for revisions, zero console errors).
* **Verified by a browser driver on 2026-10-27:** Atlas Studio was driven through headless Chrome over
  the DevTools protocol from a fresh project: add a second sketch, move it to (8, 8), join it, read
  980 mm³ / 72 triangles from the live DOM, break a feature and see the failure banner plus a
  disabled export, undo it, save. Repeated on 2026-10-29 for revolve: the option is enabled, the
  depth field hides and the axis field shows, the turn is added as a `built` row with
  `Turn: full revolution` and 3,133.72 mm³ (analytic 3,141.59), export stays enabled, and the row
  survives save and reload. The run fails on a wrong tree, a stale mesh, a console error or a
  failed request. Earlier manual checks at 392 px covered parameter rejection, profile switching,
  polygon sides, dark/light themes and the narrow-viewport drawer. These browser assertions are not
  cargo tests; the HTTP API has 19 integration tests, including the token boundary.
* **Verified earlier:** CADCraft `cadcraft-geom` passed 84 tests in the 2026-10-21 audit.
* **Advertised only (code exists, suite not run here):** all SolidCraft modules, the rest of CADCraft,
  the kernel repositories' own test suites.
* **Blocked:** OpenCASCADE/cadrum (licence decision),
  advisory scanning (tools not installed), WASM (target missing), SolidCraft's kernel tests (host
  memory).
