# Feature comparison

**Reviewed:** 2026-10-23. “Vendor states” means a product's own current pages or help. It is not a compatibility test. The “Atlas in this workspace” column is based on code and recorded local test evidence; it is intentionally narrower than the target roadmap.

| Workflow | Fusion | AutoCAD | SOLIDWORKS Design | Onshape | FreeCAD | SolveSpace | Atlas in this workspace |
|---|---|---|---|---|---|---|---|
| 2D drafting / DXF | Product drawings and manufacturing toolpaths; not a drafting-only focus | Core 2D drafting, dimensions, layouts, industry toolsets | 2D drawings from parts/assemblies | Drawings within cloud CAD | Draft/TechDraw workbenches; DXF workflow varies by workbench | Constrained 2D sketch and DXF export | CADCraft has 2D entities and DXF/DWG code; only its geometry crate is locally tested. Not a unified UI. |
| Parametric sketch constraints | Yes | Parametric constraints documented | Sketch-first feature workflow | Feature-based parametric modeling | Yes | Extensive 2D/3D constraints and DOF inspection | Named width/height/diameter/sides parameters drive one sketch; no general constraint solver. |
| 3D solids / feature history | Yes | Solids, surfaces and mesh tools | Parts and assemblies with editable feature history | Feature-based part studio | Feature-based parametric modeler | Extrude/revolve/helix and Booleans | One extrude of one rectangle, circle or polygon sketch in `cad-document`, editable and visible in Atlas Studio. The truck adapter also has verified extrude, union and intersection with recorded limits, but those are not wired to the app. |
| Assemblies | Integrated product workflows | References and industry workflows; not primary mechanical assembly authoring | Parts and assemblies are core | Collaborative assemblies and version control | Assembly workbench/ecosystem | Parametric associative assembly | Not implemented in platform workflow. |
| Drawings / annotations | Drawing automation | Mature drafting, layouts and annotation | Production drawings | Drawing tools | TechDraw | 2D vector drawing | No drawing document or annotation workflow in platform project. |
| Sheet metal / manufacturing | CAM and tiered manufacturing features | Specialized toolsets | Sheet metal and NC capabilities by plan | Manufacturing integrations vary by plan | Workbench ecosystem | G-code/toolpath export features listed by project | No validated sheet-metal or CAM workflow. STL export only. |
| Import / export | Broad CAD and manufacturing workflows | DWG/DXF-centered, plus model imports | Broad interoperability | Broad CAD import/export by subscription | STEP/DXF/SVG/PDF and other workbench formats | DXF/EPS/PDF/SVG/HPGL/STEP/STL/OBJ listed | Binary STL export and versioned native `.zcad`; no STEP/DXF import/export in platform path. |
| History / collaboration | Cloud-connected data management and collaboration | Activity insights, DWG compare and sharing | Cloud revision management and collaboration | Version control and real-time collaboration are core | Local files; add-ons/services vary | Local project model; no equivalent hosted workspace described | Atomic native save/load and bounded undo/redo for one sketch and one extrude, with schema-1 migration. No named revisions, sync or collaboration. |
| Automation / extensibility | APIs and integrated automation | AutoLISP, APIs, app ecosystem | APIs and extensions | FeatureScript and APIs | Python and workbench ecosystem | Project exposes scripting/build and constraint model | Rust contracts and a local geometry agent API exist; no stable public extension SDK. |
| Offline / deployment | Desktop with cloud-connected workflows and limited personal-use terms; offline behaviors are version/tier-specific | Desktop/web/mobile options | Local install plus cloud-connected services | Browser/cloud application | Local desktop | Local desktop | Atlas Studio is a loopback-only browser workspace over a local Rust process; no cloud call, account or native desktop window. The CLI is fully headless. |
| Price snapshot | $680/year base subscription shown on official page; offers may differ | $2,095/year US one-user annual subscription | $2,820–$4,716/year US named-user tiers | Free public/non-commercial; $1,500–$2,500/user/year commercial listed tiers | $0, LGPL application | $0, GPLv3 | No commercial product or subscription exists. |
